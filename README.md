# Blinkit-sales-analysis-insights
Blinkit Sales Analysis Dashboard | Power BI + Excel
Excited to share one of my recent Data Analytics projects — Blinkit Sales Analysis Dashboard, developed using Microsoft Power BI and Excel.

🎯 Project Objective

The goal of this project was to analyze Blinkit's sales performance, outlet distribution, product categories, customer ratings, and outlet characteristics to identify meaningful business insights and opportunities for optimization.

📊 Tools & Technologies Used

🔹 Excel – Data cleaning, preprocessing & initial data validation
🔹 Power BI – Data modeling, visualization & interactive dashboard
🔹 DAX – KPI calculations and business metrics
🔹 Power Query – Data transformation and preparation

🔍 Key KPIs Analyzed

• 💰 Total Sales: ₹1.20M
• 📈 Average Sales: ₹141
• 📦 Number of Items: 8.52K
• ⭐ Average Rating: 3.9

📌 Key Insights from the Dashboard

✅ Supermarket Type 1 contributes the highest sales, generating approximately ₹787.55K.

✅ Tier 3 outlets generated the highest sales among outlet locations at approximately ₹472.13K, followed by Tier 2 and Tier 1.

✅ Fruits & Vegetables and Snack Foods are among the leading item categories by volume.

✅ The analysis provides a clear comparison of Low Fat vs Regular products across different outlet tiers.

✅ Outlet size and location have a noticeable relationship with overall sales performance.

✅ The dashboard also tracks outlet establishment trends over time, helping understand changes in business performance.
